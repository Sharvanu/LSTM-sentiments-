# 🧠 LSTM-Based Sentiment Analysis – Python Implementation

This repository contains a full implementation of **Sentiment Analysis using an LSTM (Long Short-Term Memory) network**.  
LSTMs are a type of recurrent neural network (RNN) designed to learn long-term dependencies in sequential data—making them perfect for NLP tasks like sentiment classification.

The project processes text, trains an LSTM model, and predicts sentiment (positive/negative/neutral) on new sentences.

---

## 🚀 Features

- Text preprocessing:
  - Tokenization  
  - Lowercasing  
  - Stopword removal (optional)  
  - Padding sequences  

- LSTM model for sentiment classification  
- Word embeddings (Embedding Layer or pretrained vectors)  
- Training loop with loss and accuracy tracking  
- Evaluation on test data  
- Predict sentiment for custom inputs  
- Easy-to-read, modular code
